### RWD/RWE Solution Demo Assets in Snowflake

- Part 2: RWD Cohort Discovery Solution

This project is part 3 of the RWD/RWE demo assets.

# Project Scope & Value
 This project demonstrates the utilization of the Solution RWD Cohort Discovery deliverables for advanced patient data analytics. It imports the cohort repository and clinical covariates datasets from the RWD Solution and conducts a [retrospective analysis](https://pubmed.ncbi.nlm.nih.gov/31668726/) of the first-line angiotensin-converting enzyme inhibitor (ACEi) treatment effect using propensity score-adjusted survival analysis.  

# Project Highlights
- Leverage the robust data pipeline, generalizable OMOP CDM, reusable cohort repository, and clinical covariate tables from the Solution RWD Cohort Discovery to accelerate medical evidence generation
- Utilize the visual ML and Python recipe for causal inference
- A dashboard to review the results of the propensity score-adjusted survival analysis.

# How to use
This project is a template that demonstrates how to create a patient data analytics project on top of the RWD Solution deliverables. No installation is required.
