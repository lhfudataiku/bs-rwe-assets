This section details all the requirements needed to run this solution

The solution runs on Dataiku  **13.5+** and requires either  **Databricks**,  **Snowflake**, **Redshift**  connection.

The solution needs no dedicated code environment. The project and its Python recipe use the instance's default Python environment, which must provide **pandas** and **numpy** (the DSS built-in environment does). The solution code imports nothing else outside the Python standard library and the `dataiku` packages.
